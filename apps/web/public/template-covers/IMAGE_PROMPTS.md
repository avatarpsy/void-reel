# Voidspace Template Cover Prompts

## Storage location
Save all generated cover images in this folder:
- openreel-video/apps/web/public/template-covers/

Use these exact filenames so the UI picks them up automatically.

## Image requirements (all covers)
- Aspect ratio: 9:16 portrait
- Size: 1080x1920 (or 1440x2560)
- Style: cinematic, high-contrast, clean composition
- No text, no logos, no UI overlays, no watermarks
- Keep central subject in safe area (middle 60%) so icon/badge overlays do not hide key details
- Export format: WEBP, quality 85-92
